# Бизнес-требования: youHoo

## 1. Назначение продукта

Приложение предназначено для общения внутри семьи. Основные сценарии: обмен текстовыми сообщениями и изображениями, просмотр статусов членов семьи, работа с перепиской без подключения к интернету.

## 2. Основные функциональные требования

### 2.1. Авторизация и профили

#### Авторизация

- Вход выполняется одним из способов:
  - email и пароль;
  - одноразовый код, отправленный на email (OTP).
- При первом входе устройство регистрируется в системе.
- Сессия авторизации сохраняется: повторный вход при каждом запуске приложения не требуется.

#### Профиль пользователя

- Пользователь может изменять отображаемое имя.
- Пользователь может загружать и изменять аватар.

#### Контакты

- Список контактов предустановлен и включает членов семейного круга: мужа, жену и дочь.
- Поиск пользователей по идентификатору не требуется.
- Контакты отображаются в виде карточек с актуальными статусами.

#### Семейный статус

- Пользователь может выбрать иконку-эмодзи статуса, например:
  - 🏠 — дома;
  - 🚗 — в пути;
  - 💼 — на работе;
  - 🔋 — сплю.
- Пользователь может добавить текстовую подпись к статусу, например: «В магазине, скоро буду».
- Статус отображается в списке контактов и в шапке чата.

### 2.2. Чаты и сообщения

#### Статусы доставки

| Отображение | Значение |
|---|---|
| Одна галочка | Сообщение отправлено на сервер |
| Две серые галочки | Сообщение доставлено на устройство получателя |
| Две цветные галочки | Сообщение прочитано |

Статус «доставлено» устанавливается после получения сообщения устройством через WebSocket/Supabase Realtime или FCM.

#### Непрочитанные сообщения

- При открытии чата экран автоматически прокручивается к первому непрочитанному сообщению.
- Над первым непрочитанным сообщением отображается разделитель «Непрочитанные сообщения».
- После пролистывания непрочитанных сообщений или закрытия чата сообщения помечаются как прочитанные.
- При следующем открытии чата разделитель для уже прочитанных сообщений не отображается.

#### Удаление сообщений

- **У себя:** сообщение скрывается только для текущего пользователя и остаётся доступным другому участнику переписки.
- **У всех:** сообщение удаляется для всех участников переписки.
- После удаления «у всех» сообщение сразу исчезает с экрана и из локальной базы данных другого участника.
- Если удалённое сообщение содержало изображение, соответствующий файл также удаляется из облачного хранилища.

### 2.3. Офлайн-режим

- Переписка хранится в локальной базе данных устройства.
- Экран чата получает данные из локальной базы, а не напрямую из сети.
- При появлении нового сообщения оно сохраняется в локальной базе, после чего экран обновляется.
- При отсутствии интернета чат открывается сразу и показывает сохранённую историю переписки.

### 2.4. Быстрые реакции

- Пользователь может отправлять короткие реакции без ввода текста, например:
  - ❤️ — сердечко;
  - 🏃‍♂️ — «Выезжаю»;
  - 🍽️ — «Жду на ужин».
- Быстрый ответ можно отправить одним нажатием непосредственно из уведомления.

## 3. Будущие улучшения

Перечисленные ниже возможности не входят в основной объём требований и могут быть реализованы после дополнительного согласования.

### 3.1. Индикатор заряда батареи

- Приложение передаёт на сервер уровень заряда устройства в фоновом режиме: примерно раз в 30 минут или при отправке сообщения.
- Уровень заряда отображается рядом с контактом, например: «Жена — батарея 5%».
- Функция помогает понять возможную причину отсутствия ответа.

### 3.2. Гео-отметки по запросу

- Постоянное отслеживание местоположения не используется, чтобы сократить расход заряда батареи.
- В чате доступна кнопка «Где ты?».
- После её нажатия получателю приходит системное уведомление.
- Телефон получателя отправляет в ответ текущие координаты или название настроенной локации, например «Дом», «Школа» или «Работа».

### 3.3. Общий семейный список

- В приложении доступна отдельная вкладка для общего списка покупок или дел.
- Любой член семьи может добавлять и отмечать выполненными элементы списка.
- Изменения синхронизируются между устройствами в реальном времени.
